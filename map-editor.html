HOW TO APPLY

Apply to game downloads MapEdits.js. Save it over js/MapEdits.js, then hard-refresh index.html. The editor can also write the file directly if your browser supports it. For a separate project, use New game and Create game folder — it writes a complete standalone copy of the engine with the new map baked in.

Road tool: click to add points, double-click or press Enter to finish, Esc to cancel. Bridge tool: drag across the water — it adds a drivable road and a bridge deck.

Import data accepts OSM XML, GeoJSON, or this editor's JSON patch shape, including roads, buildings, trees, baked models and elevation. Blender can export that JSON with tools/blender_map_export.py.
