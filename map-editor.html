HOW TO APPLY

The editor loads the same baked game map: the 2D backdrop is the exact ground canvas used in-game, and roads, buildings, landmarks and coast rules come from the same runtime map data. Reset discards the current edit patch and reloads that game map.

Apply to game downloads MapEdits.js. Save it over js/MapEdits.js, then hard-refresh index.html. The editor can also write the file directly if your browser supports it. For a separate project, use New game and Create game folder — it writes a complete standalone copy of the engine with the new map baked in.

Road tool: click to add points, double-click or press Enter to finish, Esc to cancel. Bridge tool: drag across the water — it adds a drivable road and a bridge deck. Paint (W) works like a Photoshop brush: drag to stamp trees or baked models; the Brush panel controls size, spacing, scatter and scale.

2D / 3D (or P) toggles the editor view. The 3D preview renders the current map with the same baked models the game uses. Drag to orbit, right/middle/Shift+drag to pan, wheel to zoom, double-click to fit. Use Game / Realistic to switch between the in-game PS2 look and softer Blender/Unreal-style lighting, shadows and building facades. Use View / Move / Rotate / Scale (keys 1–4) for Blender-like gizmo editing of the selected building, landmark or model. For exact Blender geometry, place a baked Model asset; plain Building entries are detailed facades generated from their map dimensions.

Trailer (K): click a start point, then a finish point. Ground vehicles are routed along roads when rendered; aircraft and jetpacks fly straight to the finish. Export the shot JSON and render one clip per shot with npm run trailer -- --shots trailer-shots.json.

Blender opens the round-trip helper. The to-blender and to-editor commands carry roads, assets, baked meshes, landmarks, challenges, trailer shots and elevation between Blender 3.6 and this editor.

Import data accepts OSM XML, GeoJSON, or this editor's JSON patch shape, including roads, buildings, trees, baked models, elevation and trailer shots.
